# 代码圣诞树 🎄

两个版本，都**不需要联网、不需要装任何东西**。

```
christmas-tree/
├── index.html    ← 主推：网页版，粒子 + 辉光，最接近你发的截图
├── tree.py       ← Python 版（tkinter），命令行直接跑
├── server.py     ← 一键开局域网链接，手机连同一个 WiFi 就能看
├── make_links.py ← 批量生成“一人一网址”（配色 / 名字 / 祝福语各不相同）
└── preview.png   ← 网页版效果图
```

> 已部署：**https://zyh6669.github.io/xmas-tree/**

---

## 一、网页版（推荐）

**双击 `index.html`** 就行，Chrome / Edge / Firefox 都可以。

### 一人一条链接：改名字、祝福语、配色

在网址后面加参数即可，**同一个页面能变出无数种**：

| 参数 | 例子 | 作用 |
| --- | --- | --- |
| `to` | `?to=小明` | 第二行变成 `TO:小明` |
| `greet` | `?greet=圣诞快乐` | 第一行换掉 `Merry Christmas` |
| `msg` | `?msg=平安喜乐` | 再加一行小字的祝福 |
| `pal` | `?pal=gold` | 整套配色 |
| `still` | `?still=1` | 画面定格，方便截图 / 当壁纸 |

配色一共 7 套：

| `pal=` | 名字 | 感觉 |
| --- | --- | --- |
| `ice` | 霜蓝 | 默认，冷白偏蓝，最接近你发的截图 |
| `gold` | 暖金 | 香槟金，像暖光灯串 |
| `rose` | 樱粉 | 粉紫，偏浪漫 |
| `mint` | 薄荷 | 青绿，清爽 |
| `violet` | 紫罗兰 | 深紫 + 蓝，神秘 |
| `snow` | 初雪 | 几乎纯白，安静 |
| `aurora` | 极光 | 青绿 + 紫，最花哨 |

组合起来就是一人一条：

```
https://zyh6669.github.io/xmas-tree/?to=小明&greet=圣诞快乐&msg=平安喜乐&pal=gold
https://zyh6669.github.io/xmas-tree/?to=小美&pal=rose&msg=永远开心
https://zyh6669.github.io/xmas-tree/?to=阿杰&pal=mint
```

地址栏里中文会显示成 `%E5%B0%8F...`，这是正常的，微信/浏览器打开后就是中文。

### 批量生成

把名单写进 `people.txt`（每行 `名字,祝福语,配色`），然后 `python make_links.py`，
会打印所有链接并生成 `links.html`（双击就能逐个点开、复制）。

```
# people.txt
小明, 圣诞快乐, gold
小美, 平安喜乐, rose
阿杰, , mint
```

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `S` | 把当前画面存成 PNG（图里带字，可以直接发朋友圈） |
| `F` | 全屏 / 退出全屏 |
| 鼠标点击 / 手指点屏幕 | 在点击处炸开一小把星光 |

### 想再改点什么

打开 `index.html`，文件开头的注释下面就是可调区：

- `GREET` / `TO`：两行文案的默认值
- `PALETTE`：颜色配比（白 / 冰蓝 / 蓝 / 金 / 粉）
- `TREE = { H, R, BOT }`：树的高、底半径、底部高度 —— 想更矮胖就把 `H` 调小、`R` 调大
- `buildTree()` 里的 `strands`、`per` 和几个 `for` 循环次数：粒子数量，电脑卡就减半
- `rot += dt * 0.10`：旋转速度
- `drawText()` 里的 `x` / `y` / `fs`：文字位置和大小

## 二、Python 版

```bash
python tree.py          # 第二行显示 TO:YOU
python tree.py 小明     # 第二行显示 TO:小明
```

| 按键 | 作用 |
| --- | --- |
| `Esc` | 退出 |
| `F` | 全屏 / 还原 |
| `空格` | 暂停 / 继续 |

只用了标准库 `tkinter`，Windows 自带 Python 装好就能跑。代码里同样能改 `GREET`、`TO`、
`PALETTE` 和 `build_tree()` 里的数量。

> 说明：tkinter 没有透明和模糊，所以 Python 版是“点阵风”，没有网页版那种发光效果。

## 三、怎么让朋友看到

**① 已经部署好了（最推荐）**

GitHub Pages 已经在跑了：**https://zyh6669.github.io/xmas-tree/**

一人一条链接，直接发过去就行，不用再传文件、也不用再部署：

```
https://zyh6669.github.io/xmas-tree/?to=小明&pal=gold&msg=圣诞快乐
```

**② 就在身边 / 同一个 WiFi**

双击 `server.py`（或命令行 `python server.py`），控制台会打印一行
`http://192.168.x.x:8000/`，手机连同一个 WiFi 把这个地址输进浏览器就能看。
第一次运行 Windows 弹防火墙提示，点「允许访问」。关掉窗口就停止分享。

**③ 发文件（不用网络配置）**

把 `index.html` 直接发给对方（QQ 传文件、邮箱附件、压缩包都行），对方双击就能看。
⚠️ 微信里直接发 `.html` 有的手机会拦，建议打包成 zip 或换个方式发。

**④ 想换域名 / 换托管**

把 `index.html` 传到任意一个免费静态托管即可：

| 平台 | 特点 |
| --- | --- |
| **GitHub Pages** | 现在用的，免费、有账号就行 |
| **Netlify Drop**（netlify.com/drop） | 不用注册，把文件拖进去，几秒出链接 |
| **Cloudflare Pages** | 免费、国内访问相对稳，需要注册 |
| **Gitee Pages** | 国内快，但要实名认证 + 审核 |
| 阿里云 OSS / 腾讯云 COS | 几毛钱，稳定，适合长期放 |

换了域名后照样能用 `?to=名字&pal=配色` 定制。

**④ 只想发朋友圈**

按 `S` 存一张 PNG（图里带字），或者全屏录一段屏。手机直接拍屏幕反而更有氛围。

## 四、它是怎么画出来的

1. **点云**：9 股螺旋从底座绕到树梢，再撒一层贴面的“绒毛”、一层内部的雾、底盘的双臂星尘旋涡。
2. **3D 投影**：绕 Y 轴慢转 + 轻微俯仰，`x' = x·f/(z+cam)` 做透视，越近的点越大越亮。
3. **加法混合**：`globalCompositeOperation = 'lighter'`，密集处自然烧成一片白光。
4. **预渲染贴图**：每个颜色只生成一次 64×64 的径向渐变光点，之后全是 `drawImage`，
   一万多个粒子也能跑满 60 帧。
5. **Bloom**：把整幅画面降采样两次，再叠回主画布，就有了那层朦胧的光晕。
6. **爱心**：心形参数方程 `x=16sin³t, y=13cos t−5cos2t−2cos3t−cos4t` 采样成点。

## 五、小贴士

- 想发视频：开全屏，用 Win + G 录屏，或者手机直接拍屏幕（拍出来反而更有氛围）。
- 电脑有点卡：把 `strands` 从 9 改成 6，或把 `per` 从 760 改成 400。
- 手机上也能看：把 `index.html` 发到手机用浏览器打开，会自动变成竖屏构图。
